## function — loopback_return

What it does: Admit a desktop return URL: the address of the listener the app opened for this one sign-in attempt. The bar is the loopback literal itself, checked character by character — not a URL parse that a hostname or userinfo could slip through:  * scheme `http` exactly. Loopback has a real origin but no CA issues certificates for it; RFC 8252's native-app practice is plain http on the loopback interface, which never leaves the machine. * host the literal `127.0.0.1` or `[::1]` — not `localhost`, not any other name, not another loopback address.
