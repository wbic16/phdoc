What it does: ---------------------------------------------------------------------------------------------------------- @fn spans  Builds a borrowed span index over `input`: one `ScrollSpan` per scroll, in document order, giving each scroll's coordinate and the byte range of its text in `input`.  The walk is the `phokenize` walk — the same dimension breaks and the same coordinate arithmetic — except that it records byte ranges instead of allocating a `String` for every scroll. For every returned span, `&input[span.range]` is exactly the scroll `explode` returns at `span.coord`, and `span.range.start` is the offset `offset` reports for that coordinate.  Empty-scroll contract: a scroll exists iff it holds at least one byte — the definition `explode` encodes — so `spans` reports only non-empty scrolls. Delimiter runs that encode empty scrolls (leading breaks, runs between distant scrolls, trailing breaks) produce no span; an empty document, or a document of only delimiters, produces no spans. `phokenize` remains the tokenizer of record for empty slots: it additionally reports a final empty positioned scroll in those trailing cases, where `spans` reports none.
