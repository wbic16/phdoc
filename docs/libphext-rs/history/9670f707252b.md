## function — get_subspace_coordinates

What it does: ---------------------------------------------------------------------------------------------------------- @fn get_subspace_coordinates  finds the start and end offsets for the given coordinate  Returns `(start, end, best)`: - when the document reaches `target`, `start..end` is that scroll's text (empty if it has none) and `best` is `target`; - otherwise `start == end` is where the scroll would go: just before the break that steps past `target`, or the end of the document. `best` is the coordinate in effect there, so writing breaks from `best` up to `target` and then the text places it correctly.  The walker only moves on a dimension break, so it is compared with `target` only at the start and after each break, and the scan stops as soon as it steps past `target`.  Earlier versions returned `start = 0` for a missing coordinate that falls between two scrolls, so `fetch`, `replace`, and `remove` acted on the scroll before it, and they missed a scroll reached only by breaks at the very end of the document. ----------------------------------------------------------------------------------------------------------
